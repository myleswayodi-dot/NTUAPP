# MyNTU-App

A MyNTU-style student web app.

## Features

- Student home page
- My Course
- Student Support
- Extra-curricular
- Services
- Student Profile
- Student name and ID editing
- MyNTU branding
- Mobile-friendly layout
- Add to Home Screen support

## Student Profile

The Student Profile section allows the student to personally change:

- Student name
- Student ID number

The information is saved locally on the device.

## Files

- `index.html` — main app
- `manifest.webmanifest` — web app configuration
- `README.md` — project information
- `myntu-logo.png` — MyNTU logo

## How to use

Open the app through the published GitHub Pages website.

On iPhone, open the website in Safari and use **Add to Home Screen** to use it like an app.
